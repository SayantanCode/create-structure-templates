# {{projectName}}

React app scaffolded with Vite.

## Structure

- `src/main.jsx` — app entrypoint, mounts `<App />` into `index.html`
- `src/App.jsx` — root component; start here
- `src/assets/` — imported assets (bundled by Vite)
- `public/` — static assets served as-is (not processed by Vite)

## Adding a new component

Create a file under `src/`, import it into `App.jsx` (or wherever it should render), and Vite's dev server hot-reloads automatically.

## Getting started

```bash
npm install
npm run dev
```
